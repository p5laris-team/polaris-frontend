## 4. 화면 QA 백로그

| 화면 | QA 항목 |
|---|---|
| 홈 | 캐릭터 상태/스킨/미션 카드가 겹치지 않는지 확인 |
| 미션 기록 | 최대 15개 목록에서 스크롤/필터 상태 확인 |
| 캐릭터 돌봄 | 상태 변화 후 게이지/대사/별조각 갱신 확인 |
| 상점 | 별조각 부족/구매 완료/보유 상태 표시 확인 |
| 보관함 | 기본 외형 해제와 스킨 장착 상태 확인 |
| 출석 | 월 말/월 초 달력 레이아웃 확인 |
| 알림함 | 읽음 처리 후 목록과 홈 unreadCount 동기화 확인 |
| 공유 카드 | 카드 생성/링크 복사/Web Share fallback 확인 |
| 마이페이지 | 로그아웃/알림 설정 로컬 저장 확인 |

## 5. 결정 필요 항목

| 항목 | 선택지 | 추천 |
|---|---|---|
| 고급 애니메이션 포맷 | CSS / APNG / Lottie / Rive | MVP는 CSS, P1에서 Lottie 검토 |
| 스킨 상태별 제작 범위 | idle만 / 3상태 / 모든 행동 | MVP는 idle, P1에서 3상태 |
| 공유 카드 캡처 방식 | canvas / DOM 캡처 라이브러리 | MVP는 canvas, P1에서 DOM 캡처 검토 |
| 이스터에그 저장 | 로컬 / 서버 | MVP는 로컬 |
| 빈 상태 일러스트 스타일 | 캐릭터 중심 / 아이콘 중심 | 캐릭터 중심 |
