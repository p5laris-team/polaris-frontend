# 08. UI/UX 에셋 제작 가이드

> 목적: Polaris MVP 초안 이후 디자인/일러스트/프론트 애니메이션 작업에서 필요한 에셋을 한곳에 정리한다.  
> 기준: MVP 운영 기준을 우선하며, 액세서리/배경 장착/광고 슬롯/업적은 제외한다. 에셋 제작 범위는 캐릭터, 상태, 스킨, 공유 카드, 핵심 마이크로 인터랙션에 집중한다.

## 1. 문서 사용법

이 문서는 에셋 제작 항목의 상위 인덱스다. 세부 내용은 아래 문서로 나눠 관리한다.

- 디자이너는 [캐릭터 기본/상태 에셋](./uiux-assets/01-character-assets.md)과 [스킨 에셋](./uiux-assets/02-skin-assets.md)을 우선 확인한다.
- 프론트엔드는 [마이크로 인터랙션](./uiux-assets/03-motion-interactions.md)을 보고 구현 우선순위와 reduced motion 정책을 맞춘다.
- 기획/PM은 [이스터에그](./uiux-assets/04-easter-eggs.md)와 [제작 백로그](./uiux-assets/05-production-backlog.md)를 보고 MVP 포함 여부를 결정한다.
- 모든 에셋은 [파일 네이밍/규격](./uiux-assets/06-asset-specs.md)을 기준으로 저장한다.

## 3. MVP 우선순위 요약

### P0. MVP 초안 안정화에 필요한 에셋

| 영역 | 필요한 에셋 | 이유 |
|---|---|---|
| 캐릭터 기본 | 노바/무무/쪼리 `idle`, `happy`, `sleepy` | 홈, 돌봄, 공유 카드, 미션 완료 결과의 최소 상태 표현 |
| 캐릭터 상태 | 포만감 낮음, 기운 낮음, 애정 낮음 상태 이미지 또는 간단 모션 | 상태 게이지와 캐릭터 반응의 연결성 강화 |
| 공유 카드 | 캐릭터별 고해상도 카드용 이미지 | SCR-016 공유 카드 품질 확보 |
| 스킨 | 상점 썸네일, 보관함 썸네일, 장착 프리뷰 | 스킨 구매/장착 루프 완성 |
| 보상 연출 | 별조각 파티클, 출석 도장, 구매 완료 플래시 | 보상 획득 체감 강화 |
| 빈 상태 | 알림 없음, 보관함 없음, 미션 없음, 공유 완료 | 임시 문구 느낌 제거 |

### P1. MVP 이후 첫 폴리싱

| 영역 | 필요한 에셋 | 이유 |
|---|---|---|
| 캐릭터 탭 반응 | 1회/3회/5회 탭 대사와 짧은 모션 | 홈 체류 재미 강화 |
| 스킨 상태별 이미지 | 스킨별 `idle`, `happy`, `sleepy` | 장착 스킨의 상태 반영 |
| 알림 읽음 모션 | 카드 흐림/접힘/점 제거 | 알림함 조작감 강화 |
| 돌봄 행동 | 밥 주기, 재우기, 놀아주기 짧은 모션 | 캐릭터 애착 강화 |
| 미션 완료 | 축하 연출 변형 2~3종 | 반복 완료 피로 완화 |

### P2. 후속 확장

| 영역 | 필요한 에셋 | 이유 |
|---|---|---|
| 계절/이벤트 스킨 | 시즌 한정 스킨 | 운영 이벤트용 |
| 외부 공유 랜딩 | 카드 상세 랜딩 일러스트 | SCR-017 구현 시 필요 |
| 업적 | 배지/트로피 이미지 | 업적 MVP 제외, 후속 기능 |
| 고급 애니메이션 | Lottie/Rive 기반 루프 모션 | 앱 성능 검증 후 도입 |

## 4. 화면별 에셋 준비 지도

| 화면 | 현재 필요도 | 필요한 에셋 | 비고 |
|---|---:|---|---|
| SCR-006 홈 | P0 | 캐릭터 기본/상태 이미지, 탭 반응 후보 | 가장 많이 노출되는 화면 |
| SCR-010 미션 완료 결과 | P0 | 별조각 파티클, happy 캐릭터 | 보상 체감 핵심 |
| SCR-012 캐릭터 돌봄 | P0 | 포만감/기운/애정 상태 이미지, 돌봄 행동 모션 | 상태 변화 인지 |
| SCR-013 상점 | P0 | 스킨 썸네일, 구매 완료 연출 | 구매 전환 |
| SCR-014 보관함 | P0 | 장착 프리뷰, 기본 외형 카드, 장착 완료 연출 | 스킨 장착/해제 기준 전달 |
| SCR-016 공유 카드 | P0 | 카드용 캐릭터 이미지, 카드 배경 패턴 | 바이럴 핵심 |
| SCR-019 출석 | P1 | 출석 도장, 연속 출석 축하 | 운영 유지율 |
| SCR-020 알림함 | P1 | 알림 없음 빈 상태, 읽음 모션 | 폴리싱 |
| SCR-021 마이페이지 | P2 | 기본 프로필 아바타, 설정 아이콘 세트 | 기능 안정 후 |

| `feat: 스킨 상태 에셋 반영` | 장착 스킨의 상태별 이미지 적용 | 02, 06 기준 |
