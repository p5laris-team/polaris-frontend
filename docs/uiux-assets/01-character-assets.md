## 1. 제작 목적

캐릭터 에셋은 Polaris의 감정적 중심이다. MVP에서는 캐릭터가 복잡하게 움직이기보다, 사용자의 작은 행동에 바로 반응하는 느낌을 먼저 만든다.

핵심 원칙:

- 상태 변화는 게이지 숫자보다 캐릭터 표정과 자세로 먼저 읽혀야 한다.
- 미션 완료/출석/공유 보상은 과하지 않게 짧고 명확하게 축하한다.
- 캐릭터별 말투와 자세가 달라야 하며, 같은 상태라도 표현은 다르게 한다.
- 액세서리/배경 장착은 MVP에서 제외한다. 캐릭터 외형 변화는 스킨만 사용한다.

## 2. 캐릭터별 톤

| 캐릭터 | 키워드 | 기본 태도 | 모션 방향 |
|---|---|---|---|
| 노바 | 차분함, 별빛, 관찰자 | 조용히 응원함 | 둥실, 반짝, 고개 끄덕임 |
| 무무 | 말랑함, 순함, 작고 든든함 | 느리지만 따뜻함 | 통통, 꾸벅, 손 흔들기 |
| 쪼리 | 활발함, 산책, 장난기 | 먼저 말을 검 | 폴짝, 빠른 시선 이동, 꼬리/몸 흔들림 |

캐릭터별 대사 톤:

| 캐릭터 | 예시 |
|---|---|
| 노바 | "작은 시작도 별빛이 될 수 있어." |
| 무무 | "무... 오늘도 조금 반짝였어요." |
| 쪼리 | "좋아, 오늘의 원정 하나 성공!" |

## 3. P0 기본 에셋

| 상태 | 사용 화면 | 설명 | 우선순위 |
|---|---|---|---|
| `idle` | 홈, 캐릭터 상세, 공유 카드 | 평상시 기본 자세 | P0 |
| `happy` | 미션 완료, 출석 완료, 공유 보상 | 보상/성공 순간 | P0 |
| `sleepy` | 기운 낮음, 밤 시간대, 휴식 유도 | 졸림/피곤함 | P0 |

필수 산출물:

| 캐릭터 | idle | happy | sleepy |
|---|---|---|---|
| 노바 | 필요 | 필요 | 필요 |
| 무무 | 필요 | 필요 | 필요 |
| 쪼리 | 필요 | 필요 | 필요 |

권장 파일:

```text
character-nova-idle.png
character-nova-happy.png
character-nova-sleepy.png
character-mumu-idle.png
character-mumu-happy.png
character-mumu-sleepy.png
character-jjori-idle.png
character-jjori-happy.png
character-jjori-sleepy.png
```

## 4. 상태 에셋

상태 에셋은 포만감, 기운, 애정 게이지의 낮음 상태를 시각적으로 보조한다.

| 상태 | 트리거 | 화면 표현 | 권장 모션 |
|---|---|---|---|
| 포만감 낮음 | hunger 30 이하 | 배를 살짝 잡거나 시무룩함 | 작게 몸 숙임 |
| 기운 낮음 | energy 30 이하 | 꾸벅꾸벅 졸림 | 2초 간격 눈 깜박임 |
| 애정 낮음 | affection 30 이하 | 사용자를 힐끔 보거나 살짝 외로움 | 고개 돌렸다 돌아오기 |
| 상태 좋음 | 모든 게이지 70 초과 | 안정적이고 밝은 표정 | 느린 호흡, 작은 반짝임 |

캐릭터별 표현 예:

| 상태 | 노바 | 무무 | 쪼리 |
|---|---|---|---|
| 포만감 낮음 | 별빛이 희미해짐 | 배를 톡톡 만짐 | 바닥 냄새 맡기 |
| 기운 낮음 | 눈꺼풀이 내려감 | 꾸벅꾸벅 졸기 | 발걸음 느려짐 |
| 애정 낮음 | 시선을 피함 | 작게 움츠림 | 뒤돌아 앉음 |
| 상태 좋음 | 별빛이 안정적으로 반짝임 | 통통 흔들림 | 폴짝 대기 |

## 5. 행동 에셋

| 행동 | 사용 화면 | 권장 길이 | 설명 |
|---|---|---:|---|
| 밥 주기 | SCR-012 돌봄 | 600~900ms | 포만감 상승 |
| 재우기 | SCR-012 돌봄 | 800~1200ms | 기운 회복 |
| 놀아주기 | SCR-012 돌봄 | 700~1000ms | 애정 상승 |
| 미션 완료 | SCR-010 결과 | 1000~1400ms | 별조각 보상 연출 |
| 미션 거절 | SCR-006 홈 | 400~700ms | 실패가 아니라 괜찮다는 반응 |
| 탭 반응 | SCR-006 홈 | 300~600ms | 캐릭터를 눌렀을 때 작은 반응 |

MVP에서는 모든 행동을 고급 애니메이션으로 만들 필요는 없다. P0는 정지 이미지 + CSS transform으로 처리하고, P1에서 Lottie/Rive 전환을 검토한다.

## 6. 공유 카드용 에셋

공유 카드용 이미지는 앱 안의 작은 캐릭터 이미지보다 크게 노출된다.

요구사항:

- 투명 배경 PNG 권장
- 최소 1024px 이상 원본
- 카드 배경과 겹쳐도 외곽선이 읽혀야 함
- 스킨 장착 상태를 반영할 수 있어야 함
- 얼굴/표정이 카드 중앙에서 잘 보여야 함

공유 카드 기본 구도:

```text
[Polaris 로고]

[캐릭터 이미지]
[캐릭터 이름]
[오늘의 메시지]

[완료 미션 수] [오늘 별조각]
```

## 7. 검수 체크리스트

- [ ] 320px 모바일 폭에서도 캐릭터 실루엣이 뭉개지지 않는다.
- [ ] 밝은 배경/어두운 배경 모두에서 외곽선이 보인다.
- [ ] 상태별 차이가 표정 또는 자세로 명확히 구분된다.
- [ ] 스킨을 입혀도 캐릭터 정체성이 유지된다.
- [ ] 반복 노출 화면에서 애니메이션이 과하게 산만하지 않다.
- [ ] reduced motion 설정 시 정지 이미지로도 의미가 전달된다.
